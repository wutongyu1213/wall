为什么要装 APK？

安卓上有 OPPO / vivo / 华为 / 小米 / 三星 / UC / QQ / 夸克 等一堆浏览器，它们生成的「桌面图标」其实只是网页快捷方式，点开还带着地址栏、不够清爽。APK = 真独立 App：桌面一个校徽图标、点开全屏、没有网址栏，跟商店下载的 App 一模一样。

本 App 基于你访问的表白墙网页打包，内容实时同步线上，不占应用商店名额、不收费。iPhone 用户看网页按「添加到主屏幕」即可（苹果不用 APK）。

安装步骤（通用，所有安卓）

1点下载的 表白墙.apk，手机提示「未知来源 / 已识别风险」——这是系统安全提示，不是病毒。
2点「继续安装 / 仍要安装 / 允许」，可能要求你「设置里允许未知来源」，照提示开一下即可。
3装完桌面出现 校徽图标，点开就是全屏表白墙 ✅

② 各品牌「手机管家」提示对照（按你手机型号点）

每个厂商都会多一道安全扫描，只要它没直接删掉 / 禁止，就一定能装。看到下表的字样就放心点继续：

手机 / 系统弹出来的提示怎么点
OPPO / ColorOS（手机管家）「识别到风险 / 未识别风险来源」点 「继续安装」
vivo / iQOO（i 管理器）「安全提示 / 未知应用」点 「继续安装 / 允许」
华为 / 荣耀（手机管家）「来自未知来源 / 深度扫描」点 「仍要安装 / 继续」（步骤略多 1 步）
小米 / Redmi（安全中心）「未知来源应用」点 「继续安装」
三星（Easy 安全）「未知来源应用」直接点 「安装」（最宽松）
🔴 装不动 / 被管家拦死：个别系统版本会把「未知来源」默认关掉。此时：设置 → 安全 → 「允许安装未知应用 / 安装未知应用权限」 → 允许你下载 apk 的浏览器 → 再回来点安装即可。仍不行就退回网页 PWA 桌面快捷方式，功能完全一样，只是带个网址栏。

③ 管理员出包（PWA Builder，10 分钟）

这是 给制作者看的，同学不用管。出一次包就行，后续更新网页内容 App 会自动同步（TWA 特性）：

1电脑打开 pwabuilder.com，粘贴 https://wutongyu1213.github.io/wall/ → 点 Start。
2看到「All PWA checks passed」后，展开 TWA 区块 → 点 Download APK（会先下载 TWA 模板，按提示填 App 名/包名，包名留默认即可）。
3生成 app-debug.apk。若需正式签名：PWA Builder 会提示「Download Bubblewrap」命令行，按提示 signing key + 上传 Google Play 或本地图谱分发。校内小范围可直接把 app-debug.apk 发群（需对方允许未知来源）。
4把 apk 传到 网盘 / 班级群文件，把链接告诉我，我写进本页「立即下载」按钮里。
📌 诚实边界：不上应用商店（学生项目无实名开发者账号、上架需费用 + 审核），所以是「传 apk 文件安装」方式，每个同学第一次装会看到「未知来源」提示（对照第②节点继续即可）。若将来要「零提示」上架，需付费应用市场，非现在所需。

④ 装好了之后

  • 桌面图标 = 校徽，点开全屏、无地址栏，跟 App 一模一样。
  • 内容和网页实时同步：后台改公告/投票，App 打开即是最新。
  • 更新 App：直接删旧的装新 apk（或走 TWA 自动更新），不用手动。
  • iPhone 用户不适用本页，走「添加到主屏幕」。
